# Marketing Campaign Analytics Dashboard

## About the Project

This project was developed as part of my Data Science learning journey. The dashboard analyzes marketing campaign
data and provides insights on campaign performance, revenue, ROI, conversions, brands, and marketing channels.

The project is built using Python, Streamlit, SQLite, Pandas, Plotly, and Machine Learning.

## Features

* Campaign Performance Analysis
* Channel Analysis
* Brand Analysis
* Customer Insights
* Revenue Prediction
* Profit/Loss Prediction

## Tools and Technologies

* Python
* Streamlit
* Pandas
* SQLite
* Plotly
* Scikit-learn
* Joblib
